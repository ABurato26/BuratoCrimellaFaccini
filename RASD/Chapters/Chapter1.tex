\section{Purpose}
\subsection{Goals}
Here are the goals that BBP has to fulfill. BBP has to:
\begin{itemize}
	\item G1: Recognize suitable bike paths
	\item G2: Allow the user to browse different bike paths
	\item G3: Allow the user to see bike paths statistics
	\item G4: Allow the user to search for paths between two locations
	\item G5: Allow the user to see paths optimality based on other registered users' reviews	
	\item G6: Allow user to see weather information when available
	
	\item G7: Allow users to register to the application using credentials
	\item G8: Allow registered user to review published bike paths	
	\item G9: Allow registered user to confirm or reject false positives in track recording
	\item G10: Allow registered user to let the system to automatically record suitable bike paths
	\item G11: Allow registered user to manually create suitable bike paths 
	\item G12: Allow registered user to publish bike paths
	\item G13: Allow the store of bike paths data for registered users
	\item G14: Allow registered user to add publishable information about bike paths
	
	
	
\end{itemize}
