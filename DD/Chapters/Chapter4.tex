\section{Requirements Traceability}

This section describes the traceability between the system requirements and the software components responsible for their implementation. Each requirement defined in Section~3.2.1 is mapped to the manager that fulfills it.

\subsection*{Authentication Manager}
\begin{itemize}
	\item R1: The system shall allow new users to register an account
	\item R2: The system shall allow users not registered to access without an account
	\item R3: The system shall allow registered users to log in to the application
	\item R5: The system shall allow users to log out of their current session
\end{itemize}

\subsection*{Profile Manager}
\begin{itemize}
	\item R4: The system shall allow registered users to view and update their personal profile information
\end{itemize}

\subsection*{Recording Manager}
\begin{itemize}
	\item R6: The system shall allow registered users to record their cycling trips
	\item R8: The system shall compute and display total distance covered for each trip
	\item R9: The system shall compute and display average speed for each trip
	\item R10: The system shall compute and display total time spent for each trip
	\item R11: The system shall compute and display elevation gain for each trip
	\item R12: The system shall compute and display calories spent for each trip
	\item R13: The system shall compute and display additional performance metrics for the trips
	\item R26: The system shall automatically infer that the registered user is cycling based on their speed
	\item R27: The system shall collect GPS data to reconstruct the path followed by the user during the ride
	\item R28: The system shall acquire data from the mobile device’s accelerometer and gyroscope
	\item R29: The system shall analyze sensor data to identify potential path irregularities
	\item R30: The system shall require the user to confirm or correct automatically acquired data
	\item R45: The system shall allow registered users to manually insert the duration of the trip
	\item R47: The system shall allow registered users to visualize a summary of the trip
\end{itemize}

\subsection*{Storage Manager}
\begin{itemize}
	\item R7: The system shall store recorded trips to maintain a history of cycling activities
	\item R38: The system shall collect paths data and keep it saved
\end{itemize}

\subsection*{Look \& Publish Manager}
\begin{itemize}
	\item R15: The system shall allow registered users to insert information about bike paths
	\item R16: The system shall allow registered users to make bike path information publishable
	\item R17: The system shall allow registered users to add information about the status of a bike path
	\item R18: The system shall allow registered users to add the presence of obstacles on a bike path
	\item R22: The system shall allow registered users to manually insert bike path data
	\item R23: The system shall allow registered users to manually specify the status of the street
	\item R24: The system shall allow users to manually report the presence of obstacles
	\item R31: The system shall allow registered users to mark their data as publishable
	\item R32: The system shall merge information about the same path from multiple users
	\item R33: The system shall prioritize data based on timeframe and confirmations
	\item R46: The system shall distinguish between public and private trips
\end{itemize}

\subsection*{Search Manager}
\begin{itemize}
	\item R20: The system shall calculate the distance of a path
	\item R34: The system shall allow any user to search for bike paths by origin and destination
	\item R35: The system shall find bike paths connecting the specified origin and destination
	\item R36: The system shall visualize bike paths on a map
	\item R37: The system shall compute a score for each path
	\item R39: If multiple paths exist, the system shall display them sorted by score
	\item R41: The system shall filter paths through various attributes
	\item R42: The system shall allow the user to search through public paths
\end{itemize}

\subsection*{Dashboard Manager}
\begin{itemize}
	\item R40: The system shall visualize paths data
\end{itemize}

\subsection*{Notification Manager}
\begin{itemize}
	\item R30: The system shall require user confirmation of automatically acquired data
\end{itemize}

\subsection*{Query Manager}
\begin{itemize}
	\item R25: The system shall recognize when users are cycling on an existing bike path
	\item R26: The system shall recognize when users are cycling on low-traffic roads
\end{itemize}

\subsection*{External API Integration}
\begin{itemize}
	\item R14: The system shall retrieve meteorological data from an external service
	\item R43: The system shall communicate with a weather API
	\item R44: The system shall communicate with an API for finding cycling routes
	\item R45: The system shall communicate with an API to calculate distances between coordinates
\end{itemize}
