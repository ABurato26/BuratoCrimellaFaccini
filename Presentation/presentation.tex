\begin{frame}{System Dynamics \& Data Lifecycle}
    \begin{itemize}
        \item \textbf{Acquisition Strategy}: hybrid model using \textbf{inference} (speed thresholds) and \textbf{topological reconstruction} (manual)
        \item \textbf{Validation Pattern}: sensor anomalies are flagged as "\textbf{candidates}" to filter \textbf{false positives} via user confirmation
        \item \textbf{Consistency Logic}: server-side \textbf{weighting algorithm} resolves conflicts based on data freshness and consensus
    \end{itemize}
